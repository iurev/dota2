# Anki files

## Keyboard columns

Import `keyboard-columns.txt` into Anki. It contains 26 separate notes using
the **Basic (and reversed card)** note type, so Anki creates 52 cards:

- number → letter
- letter → number

The hidden letter on the number side keeps notes such as `1 ↔ Q`, `1 ↔ A`,
and `1 ↔ Z` separate while showing only `1` during review.
